#2048 and 6561 Game

This repository contains a Python implementation of the popular 2048 game with an additional twist: a variant called 6561. The game is built using the pygame library for the main game interface and tkinter for dialog boxes or other UI elements.

Features:
Play the classic 2048 game.
Switch to the 6561 mode for a new challenge.
Smooth animations and an intuitive interface.
Interactive pop-ups or settings implemented with tkinter.

Gameplay:
Use the arrow keys to slide tiles.
Combine tiles with the same number to create higher-numbered tiles.
The game ends when there are no valid moves left.

Technologies Used:
Python: Programming language used for the entire project.
Pygame: For rendering the game board and handling user interactions.
Tkinter: For additional UI components like dialogs or settings.
